# 数据来源与处理说明

## 原始资料

- 文件：`アニメ基礎知識大百科.pdf`
- 页数：224 页
- 形式：扫描版日文图书，PDF 内没有可提取的文本层
- 本文档使用范围：第 1 章与第 3 章中与动画制作流程、岗位职责、术语有关的页面

## 为什么没有直接批量 OCR

- `pypdf` 对全部 224 页提取出的文本长度为 0，说明 PDF 只有页面图像。
- 当前 Windows Tesseract 只安装了英文语言模型，无法可靠识别日文假名和术语。
- 直接使用英文 OCR 会把日文大量识别成乱码，后续检索和评测都会失真。
- 因此没有把整本 224 页机械导入，而是选定了任务 A 所需要的一个垂直小 topic，并逐页查看原始页面后整理知识条目。

## 整理方式

- 保留日文术语，例如 `制作進行`、`絵コンテ`、`レイアウト`、`原画`、`動画`、`仕上`、`撮影`。
- 中文内容是根据页面意思形成的知识摘要，不是逐字翻译，也不是出版商原文。
- 每个知识条目记录 `page_start`、`page_end` 和一句日文原文线索，方便人工回溯。
- 不把无法确认的细节补进知识库；范围外问题按“资料不足”处理。

## 当前数据边界

- 只覆盖流程和岗位相关页面，不覆盖整本词典。
- 不包含具体新番、制作公司最新信息、员工薪资、制作委员会收益分配。
- 由于是人工阅读整理，仍可能存在误读或摘要不完全的情况；评测结果不等同于对原书全部内容的覆盖。
